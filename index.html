Formeln

x   = 0.622 * p_D / (p - p_D)
φ   = p_D / p_s(t)
h   = 1.006 * t + x * (2501 + 1.86 * t)
ρ   = (1 + x) / v
v   = (R_L + x * R_D) * T / p
p_s : Sonntag (1990), unter 0 °C ueber Eis
